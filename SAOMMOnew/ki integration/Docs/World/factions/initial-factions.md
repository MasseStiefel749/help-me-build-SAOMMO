# Initial Factions — World Design

**Status:** Concept — not all factions active at game start
**Authority:** Band 7 §6, Band 4 §13–14
**Date:** 2026-08-15

These are **archetypes** for world design. Each entry must gain territory, relationships, and a representative NPC before becoming full canon.

---

## 1. Reconstruction Orders

**Theme:** Reconstruction vs. tradition (Band 7 §5)

| Field | Detail |
| ----- | ------ |
| Purpose | Rebuild civil society — trade, food, infrastructure, governance |
| Attitude to blade culture | Respect skill, reject blade worship that caused the fall |
| Territory | Brunnfeld and similar settlements (concept) |
| Representative archetype | Council elder, mason foreman, supply coordinator |
| Player relationship | Default neutral-friendly; quests about rebuilding |

**In Starting Reach:** Brunnfeld visually and politically leans toward this faction. No formal faction UI in vertical slice.

---

## 2. Blade Traditions

**Theme:** Respect vs. reverence

| Field | Detail |
| ----- | ------ |
| Purpose | Preserve sword arts — schools, wandering masters, dueling codes |
| Attitude | Discipline and mastery; wary of repeating civilization's excess |
| Territory | Klingenhof and scattered dojos (concept) |
| Representative archetype | Blade instructor, retired champion |
| Player relationship | Training, sparring, reputation through skill |

**In Starting Reach:** Klingenhof is their visible footprint. Instructor NPC post-slice.

---

## 3. Artifact Seekers

**Theme:** Hidden power, personal path

| Field | Detail |
| ----- | ------ |
| Purpose | Find, study, or claim ancient Artifacts |
| Attitude | Ambitious, competitive, sometimes reckless |
| Territory | No fixed base — camps, ruins, scholar enclaves |
| Representative archetype | Treasure hunter, relic scholar, rival adventurer |
| Player relationship | Competition, information, moral choices about Artifacts |

**In Starting Reach:** Ruine des Ersten Griffs attracts them indirectly — rumors at Brunnfeld inn (post-slice dialogue).

---

## 4. Local Authorities

**Theme:** Living world, order vs. freedom

| Field | Detail |
| ----- | ------ |
| Purpose | Guard settlements, enforce local law, tax and protect |
| Attitude | Pragmatic — need swords but fear unchecked violence |
| Territory | Brunnfeld guard post, road checkpoints |
| Representative archetype | Guard captain, patrol sergeant |
| Player relationship | Lawful conduct rewarded; bandit kills welcomed |

**In Starting Reach:** Small guard presence in Brunnfeld; optional patrol in Grauwaldrand later.

---

## 5. Faction Relationship Matrix (Concept)

```text
                    Reconstruction  Blade Trad.  Artifact Seek.  Local Auth.
Reconstruction Orders      —           cordial        wary          allied
Blade Traditions        cordial          —          neutral        respectful
Artifact Seekers           wary         neutral         —           tense
Local Authorities       allied      respectful      tense            —
```

**cordial** = cooperate on shared goals  
**wary** = ideological friction, not open war  
**tense** = jurisdiction conflicts  

Full faction system is **post-MMO infrastructure**. This matrix guides dialogue and quest tone only.

---

## 6. Adding a New Faction

Required before canon:

1. Purpose tied to Band 7 theme
2. Named territory or mobile pattern
3. At least one NPC archetype
4. Relationships to existing factions
5. No contradiction with lore anchor
6. Author approval if faction affects Starting Reach politics
